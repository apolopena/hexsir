## Instructions

Regenerate the manifest file `rw/findings/STATUS.md` by greping every finding doc's canonical `**Status:**` line and writing a markdown table to disk. **Implementation is grep-based, not LLM-semantic** — do not summarize, do not rephrase, do not infer. The grep is the source of truth.

### Mechanics

Run the following pipeline (Bash):

```bash
{
  echo "# Findings status manifest"
  echo
  echo "Auto-regenerated by \`/findings-status\`. Do not edit by hand — edits are clobbered on next run."
  echo "Source of truth: the \`**Status:**\` line at the top of each \`rw/findings/<name>.md\`."
  echo
  echo "| Status | File | Topic |"
  echo "|---|---|---|"
} > /tmp/findings-status.md

# For each finding, extract its canonical Status line
python3 - <<'PYEOF' >> /tmp/findings-status.md
import os, re
DIR = "rw/findings"
SKIP = {"README.md", "STATUS.md"}
canonical = re.compile(r'^\*\*Status:\*\* (in-progress|confirmed|archived)$', re.M)
title_re = re.compile(r'^# (.+)$', re.M)
rows = []
for fn in sorted(os.listdir(DIR)):
    if not fn.endswith(".md") or fn in SKIP:
        continue
    path = f"{DIR}/{fn}"
    with open(path) as f:
        text = f.read()
    matches = canonical.findall(text)
    title_m = title_re.search(text)
    title = (title_m.group(1) if title_m else "").strip()
    if len(matches) == 1:
        status = matches[0]
    else:
        status = "?"
        if not matches:
            title = (title + " — _no canonical Status line_").strip()
        else:
            title = (title + f" — _{len(matches)} conflicting Status lines_").strip()
    rows.append((status, fn, title))
# Sort: in-progress, confirmed, archived, ?  then alphabetical
order = {"in-progress": 0, "confirmed": 1, "archived": 2, "?": 3}
rows.sort(key=lambda r: (order.get(r[0], 9), r[1]))
for status, fn, title in rows:
    print(f"| {status} | [{fn}]({fn}) | {title} |")
PYEOF

mv /tmp/findings-status.md rw/findings/STATUS.md
```

After writing, print a one-line confirmation: `Wrote rw/findings/STATUS.md (N entries)` where N is the row count.

### Constraints

- The grep contract is mandatory: every finding has exactly one `^\*\*Status:\*\* (in-progress|confirmed|archived)$` line. Conflicting / missing matches surface as `?` rows so reviewers can fix them.
- Do not alter individual finding docs. This command only writes `STATUS.md`.
- No hooks, no CI integration. Run on demand.
