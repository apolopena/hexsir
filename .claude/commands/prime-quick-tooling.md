## Purpose
This command primes the session for tool-development work. It reads the context pack generated by `/prime-full-tooling` (in `.ai/scratch/tooling-context/`) plus `docs/tools/coding-standards.md` — the one cross-cutting doc that applies to any tool — then prints a short orientation. Per-group tool docs and the other cross-cutting docs are opened on demand, not primed. It does no regeneration and is not coupled to any other command file — if the context pack is missing or stale, run `/prime-full-tooling`.

## Instructions
Read `CLAUDE.md`, then:

1. **Assert context files exist** in `.ai/scratch/tooling-context/`:
   - `tooling-arch.md`
   - `tooling-context.md`
   - `tooling-dev.md`
   - `tooling-index.md`

   If any are missing, error and tell user to run `/prime-full-tooling` first.

2. **Read fully, in parallel** — every file end-to-end, never sampled:
   - The four context files above.
   - `docs/tools/coding-standards.md`.

   Per-group tool docs (`adcli.md`, `evalcli.md`, etc.) and the other cross-cutting docs (`README.md`, `creating-a-new-tool.md`) are intentionally **not** primed. The context files name them and point to them — open only what the task actually needs.

3. **Print the user report** per the **User Report Format (canonical)** section below. For this command, the user report is the entire output — nothing else is printed.

**CRITICAL**:
- Step 2's reads all happen in parallel in one message. The user report prints last.
- Format results for human readability.

## User Report Format (canonical)

This section is the single source of truth for user-report output. Any command that emits a user report (`/prime-quick-tooling`, `/prime-full-tooling`, future variants) must use these exact literals so every entry point looks identical. Do not drift.

**Header** — first line of the user report, byte-exact:

```
🧰 🛠️ 🧪
```

Three specific emojis, space-separated, no surrounding text.

**Body** — blank line after the header, then echo `tooling-context.md` from the `## Intro` heading through the end of `## Indexed-only`, verbatim. Omit only the top-level `# Tooling Context` title. Everything from `## Intro` onward — headings, blurbs, bullets — is printed unchanged.

**Closing** — blank line after the body, then byte-exact:

```
🔧 Tooling primed and ready!
```

**Pin rules:**
- Header and closing are byte-exact literals. Do not change emojis, spacing, capitalization, or punctuation.
- Body is 1:1 with `tooling-context.md`. No editorializing, no reordering, no dropping blurbs.
- The three parts appear consecutively. Commands that emit additional content (regeneration summaries, scan tables) place that content outside the user report — before the header or after the closing — never interleaved.
